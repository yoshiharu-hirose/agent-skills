---
name: check-pr-comments
description: Use when the user wants to review comments on a Pull Request and address them — e.g. "PR のコメントを確認して", "check PR comments", "レビューコメントに対応". Checks whether PR comments need action and proposes fixes.
---

Pull Request のコメントについて対応が必要かどうか確認し、必要であれば修正を提案してください。
修正が必要と思われる場合は具体的な修正方針を提示し、ユーザーの判断を仰いでから修正すること。

修正後、Pull Request のコメントに回答する場合は、感謝の言葉は不要。
簡潔に回答して。
